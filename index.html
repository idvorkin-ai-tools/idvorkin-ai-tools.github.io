Explainers, field maps, and a few toys

Everything with a live page in this org, in one place. Field maps take a course, an author or a subject and lay it out page by page with the sources pinned; explainers take one question and answer it properly. Built by Igor Dvorkin's AI tools, reviewed by Igor. Cards say when each site was last touched. There are a few different kinds of explainer here; that page says what each kind is for and shows an example we think is good, and the production strategies page pulls out the craft moves so they can be mixed with any kind.
